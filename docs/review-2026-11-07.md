## 🔴 必修（2）

### 🔴-1 奖项语言筛选完全失效：`#book-award-lang-row` 悬空选择器

- **位置**：`src/pages/index.astro:359`、`src/pages/index.astro:363`
- **问题**：脚本用 `document.querySelectorAll('#book-award-lang-row .chip')` 绑定奖项语言筛选的点击事件，但模板里该行是 `<div class="filter-row" data-bview="awards">`（`src/pages/index.astro:51`），**没有 `id="book-award-lang-row"`**。已在构建产物 `dist/index.html` 里确认：该 id 只出现在脚本字符串里，标记里不存在。结果：四个奖项语言 chip（全部/中文/英文/国际）没有任何 click 监听，点击无反应，`applyAwardLang()` 只在初始时跑一次（空集合 = 全显示），奖项语言筛选静默失效。
- **修复建议**：给模板行补 id（`src/pages/index.astro:51` 改为 `<div class="filter-row" id="book-award-lang-row" data-bview="awards">`），或把脚本选择器改成 `#book-filters [data-bview="awards"] .chip`。修完后按 QA 矩阵验证奖项视图筛选。

### 🔴-2 视频详情页复制按钮报错：客户端脚本用了未导入的 `t` / `getLang`

- **位置**：`src/pages/video/[bvid].astro:260`（`<script>` 块 228–263 行）
- **问题**：脚本里 `flash(btn, t('copied', getLang()))`，但 `<script>` 是独立的前端模块，**frontmatter 的 `import { t, getLang } from '../../lib/i18n.ts'`（第 20 行）不会带进脚本块**，脚本内也没有自己的 import。已在 `dist/video/BV19T4y1E7VN/index.html` 的内联 module 里确认：无 import、无 `t` 定义。运行时点击「复制链接」→ 链接已写入剪贴板，但随后抛 `ReferenceError: t is not defined`，「✅ 已复制」反馈永不显示。
- **修复建议**：在该 `<script>` 顶部补 `import { t, getLang } from '../../lib/i18n.ts';`。

### 🟡-2 `build_books.py` 去重分支先使用后赋值 `aid` / `aid_year`

- **问题**：`collect()` 里重复书名的分支引用 `aid`/`aid_year`，但这两个变量是**上一本新书**解析出的值（Python 闭包外泄到循环）。边界场景下会把上一本书的奖项错挂到当前书：当同一书名出现在多个清单文件、且首次出现没解析出奖项（`award_id=None`）、而上一行新书恰好解析出奖项时。目前 `data/curated/book-links-*.md` 数据量小、暂未见错挂，但属于潜伏的悬空引用。
- **修复建议**：把 `aid, aid_name, aid_year = parse_award(src, blurb)` 上移到 `if title in pool:` 之前；顺带删掉 `merge()` 里 316 行重复的 `t = tagged.get(b["title"])` 和 305 行未使用的 `theme_en`。

### 🟡-3 视频详情页「在 B 站看全部」硬编码中文、措辞写死 B 站
