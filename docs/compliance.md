# 合规自查清单（stage 6）

发布公开版之前逐项核对。任何一项不过关就先解决再发布。

## 内容合规

- [ ] **只收录儿童适宜内容**：所有条目经 LLM 打标 `suitable=true`（scripts/tag.py 审核标准见脚本内注释），人工抽检 ≥20 条
- [ ] **无盗版搬运内容**：优先收录原创 UP 主与官方账号；发现明显盗搬（影视切片、未授权字幕组内容）一律不收录
- [ ] **无软广带货**：标题/简介含带货、引流、优惠信息的剔除
- [ ] 标签口径一致：年龄段/语言/主题均来自 taxonomy.json 枚举

## 平台规则（B 站）

- [ ] **只用官方 embed**：播放一律走 `player.bilibili.com` iframe，不自建播放器、不解析视频流地址
- [ ] **不抓取视频内容**：管线只调用公开元数据 API（view 接口），不下载视频、不抓弹幕评论
- [ ] **遵守 robots 与频控**：采集脚本带 ≥2s 请求间隔，不并发轰炸
- [ ] 封面图来自 B 站 CDN 并带 `referrerpolicy="no-referrer"`；如收到 B 站方异议，立即下架相关图片改用文字卡片
- [ ] 每个视频卡片保留原视频页链接（复制链接 / 点击封面跳转），为 UP 主导流

## 站点自身

- [ ] **无追踪**：无 analytics、无 cookie、无第三方统计脚本
- [ ] 无用户数据收集（没有表单、没有登录）
- [ ] 隐私声明：README 与站点页脚注明"不收集任何访问者数据"
- [ ] 免责声明：内容索引自 B 站，版权归原 UP 主所有；下架联系渠道（GitHub issue）
- [ ] MIT LICENSE 文件在位

## 知识产权与下架机制

- [ ] 站点性质是**链接索引 + 官方播放器**，不复制、不存储任何视频资源
- [ ] README 写明下架流程：UP 主或权利人开 issue 即可要求移除条目，承诺 7 天内处理
- [ ] 定期复查：每次快照更新时，抽查已下架/删失视频（view API 404 的条目自动剔除）

## 发布

- [ ] repo 描述、README、站点页脚三者口径一致
- [ ] 首帖发布渠道：RIGE-762 记录的亲子论坛/社区（发布文案单独拟稿）
- [ ] 发布后观察一周：GitHub issue、播放异常反馈
