采集日期：2026-11-07。共 **57 本**。格式与站点其他书单一致：`书名 | 作者 | 链接 | 推荐语 | 奖项 年份`。

## 范围与说明

1. **凯迪克奖 Caldecott 2017–2026 已在 `book-links-2026-11-07-en.md` 收录，本文件跳过。**
2. 收录年份：2021–2025（BIB 双年展为 2021/2023/2025 三届）；每奖项每年取首奖（金奖/medal/大赏/首奖）+ 优选/银奖（shadowers' choice / 佳作奖等，如易得）。提名长名单不收。
3. 只收绘本；两届格林纳威/卡内基插画金奖为图像小说形式（2022《Long Way Down》、2023《Saving Sorya》），已保留并在推荐语注明"偏大童"。
4. **德国奖说明**：任务指定的 `bilderbuchpreis.info` 域名已无法解析（DNS 失效，2026-11-07 实测），改用德国最权威的**德国青少年文学奖"绘本"类别**（Deutscher Jugendliteraturpreis – Bilderbuch，jugendliteratur.org），历届名单经德文维基百科核对。
5. 链接规则：中文原创（陈伯吹/信谊/BIB 中国获奖者/BRAW 中国获奖者）优先给豆瓣（subject ID 经豆瓣 suggest API 逐条验证，全部 HTTP 200）；国际奖项给奖项官方页或权威媒体报道（Publishing Perspectives / Publishers Weekly / carnegies.co.uk 等，均经 HTTP 校验为 200）。日本绘本赏多条目同时存在豆瓣收录的日文原版条目，已优先给出。
6. 去重：与既有 `book-links-*.md` 全量比对，无重复条目；唯一跨奖重复为 *Small in the City*（2021 格林纳威金奖 + 2021 德国青少年文学奖绘本奖），已合并为一条并在推荐语注明。
