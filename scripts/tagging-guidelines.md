# 童心岛打标准则 v1

所有打标（LLM API 或打标子 agent）必须遵守本文件。输出不符合本文件的内容会在
校验环节被丢弃。

## 输入

每条候选包含：`bvid`、`title`（标题）、`up`（UP 主名）、`desc`（简介，可能为空）。

## 输出格式

只输出 JSON 数组，每个元素：

```json
{
  "bvid": "BVxxxxxxxxxx",
  "suitable": true,
  "age": ["3-6"],
  "language": ["zh"],
  "theme": ["science"],
  "note": "一句话理由（≤40字）"
}
```

`suitable=false` 时 `age`/`language`/`theme` 给空数组，`note` 说明淘汰原因。

## 一、适宜性判断（suitable）

**通过**（面向儿童或亲子共看）：
- 知识科普（自然、物理、数学、历史、生物……）
- 动画/儿歌/绘本故事
- 英语/语文等学科启蒙
- 音乐、美术、手工、书法等素质内容
- 适合家长陪同观看的纪录片、展览、文化节目

**淘汰**（suitable=false）：
- 暴力、恐怖、血腥、性暗示等成人化内容
- 标题党、口水擦边、低质剪辑号
- 软广带货、引流、优惠信息
- 纯游戏实况/电竞（除非是面向儿童的教学，如编程启蒙）
- 成人向吐槽、社会争议、政治敏感内容
- 时长超过 45 分钟的单集正剧/电影（除非是高质量纪录片且明显适合亲子）

**边界规则**：
- 面向家长的"如何辅导"类内容不收录（受众是家长不是孩子）
- UP 主讲解类科普即使语言偏成人（如李永乐、毕导），只要内容健康就 `suitable=true`，
  年龄段给大童档
- 儿歌/动画合集类：单集时长无关紧要，按内容判断

## 二、年龄段（age，可多选，从枚举取值）

枚举：`0-3` / `3-6` / `6-9` / `9-12`

判据（按内容复杂度与语言难度，不按 UP 主名气）：
- `0-3`：慢速儿歌、认知启蒙（颜色形状动物）、低幼动画（小猪佩奇级语速）
- `3-6`：故事绘本、基础英语启蒙、简单科普（为什么系列）、儿歌进阶
- `6-9`：成体系的科普（十万个为什么级）、数学思维、自然纪录片、初阶人文
- `9-12`：进阶科普（物理/化学原理）、历史深度内容、古诗词讲解、外刊/长讲解
- 儿童动画剧集（如 Numberblocks）：`3-6` 或 `3-8` → 填 `3-6`（枚举里没有 8）
- 讲解类科普（李永乐/毕导/吴姥姥）：`6-9` 和 `9-12`
- 古生物/历史深度（芳斯塔芙/韩茂莉）：`9-12`
- 拿不准时选更小的一档宁低勿高

## 三、语言（language，只填一个主语言）

枚举：`zh` / `en` / `bilingual`

- 中文讲解、中文儿歌、中文字幕国产动画 → `zh`
- 纯英文内容（英文儿歌、英文动画原声）→ `en`
- 双语教学、英文内容配中文字幕讲解、英语启蒙课 → `bilingual`
- 中文视频里夹英文单词（如混知）→ 仍算 `zh`
- 英文内容配中文字幕但没有讲解 → `en`

## 四、主题（theme，1-3 个，从枚举取值）

枚举：`science` 科普 / `animation` 动画 / `story` 绘本故事 / `music` 音乐 /
`math` 数学思维 / `english` 英语启蒙 / `nature` 自然 / `life` 生活习惯 /
`social` 情感与社交 / `craft` 手工

- 主题填**内容的主要从属**，不按标题关键词硬套
- 数理科普 → `math` 或 `science`（物理化学生物天文 → `science`；数学/逻辑 → `math`）
- 动物/植物/地球 → `nature`；物理实验演示 → `science`
- 动画形式的科普（如美丽科学）→ `science` 为主 + `animation`
- 古诗词/历史/语文 → 枚举里没有对应项时选 `story`（人文叙事类暂归此档）并在
  note 里注明"建议增设人文主题"——枚举扩展走仓库 issue，不打标 agent 自行扩展
- 音乐儿歌 → `music`；英文儿歌 → `music` + `english`
- 手工/折纸/美术 → `craft`

## 四-B、绘本（图书）打标补充

绘本书单（build_books 管线）的"主题"使用**图书专属枚举**，与视频枚举不同：

枚举：`stories` 成长故事 / `emotions` 情绪社交 / `knowledge` 科普认知 /
`nature` 自然动物 / `math` 数学逻辑 / `english` 英语启蒙 /
`literacy` 语言人文 / `habits` 生活习惯 / `art` 艺术美育 / `interactive` 游戏互动

- 故事主线、成长、想象 → `stories`；情绪管理、友谊、生命教育 → `emotions`
- 百科/科学/身体 → `knowledge`；动物/自然/环保 → `nature`
- 古诗、国学、历史、民俗、语文 → **`literacy`**（视频枚举的欠账已在图书侧补上）
- 刷牙/如厕/安全 → `habits`；音乐/美术/创意 → `art`；翻翻书/游戏书 → `interactive`
- reason_zh 里**不要再写**"建议增设人文主题"之类的备注（枚举已齐）

## 五、一致性要求

- 同一 UP 主的同类视频标签应一致（同一判据）
- 拿不准的条目宁可 `suitable=true` 但 note 里写"待人工复核"，不要乱猜
- 不输出 JSON 以外的任何文字（没有 markdown 围栏、没有解释）
